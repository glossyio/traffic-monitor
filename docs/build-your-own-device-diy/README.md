# Build your own

A Traffic Monitor is a Raspberry Pi 5, a camera, an optional radar and AI accelerator, and a weather-resistant enclosure. Building one takes an afternoon.

1. [Hardware](recommended-hardware.md): the parts list, with the options that have been tested.
2. [Assembly](assembly-instructions.md): fitting the parts into the 3D-printed enclosure.
3. [Install the software](../software-installation.md): image the microSD card and run the installer.
4. [Update the software](update.md): when a new release comes out.

Then continue with [Choose a site and mount](../deployment-and-mounting-guide.md) and [First-time setup](../setup-guide.md).
