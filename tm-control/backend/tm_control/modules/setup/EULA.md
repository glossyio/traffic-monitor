# Traffic Monitor end-user license agreement

This is a placeholder. The Traffic Monitor project will supply the final wording of this agreement before it is
released.

Until then, this placeholder stands in for it so that setup can record which version of the agreement the device's
admin accepted. When the final wording replaces it, its version number changes, and an admin is asked to read and
accept the new version before anyone can use the device's apps again.
