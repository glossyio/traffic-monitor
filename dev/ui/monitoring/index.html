    Monitoring¶

    On-device Monitoring dashboard

    Success

    The local, on-device Traffic Monitor dashboard is available by connecting directly to your traffic monitor via a web browser.

    The Monitoring tab display counts and descriptive statistics among all your sensors.

    Sample screenshot¶

    Descriptions¶

    1. Select your Radar and Camera in case you have multiple sensors on the unit. Sensors need to be defined and enabled in the Node-RED Config.
    2. Displays car object speed counts and descriptive statistics for those that moved through zone_radar since 0400 local time. Stats include:
    3. count: Total count through valid area
    4. mean_speed: Average speed among all cars
    5. p25_speed: 25th Percentile speed, also known as first quartile (Q1)
    6. p50_speed: 50th Percentile speed, also known as median speed
    7. p75_speed: 75th Percentile speed, also known as third quartile (Q3)
    8. p85_speed: 85th Percentile speed
    9. max_speed: Maximum speed
    10. count_over_25: Static set number for maximum speed (25 in set system; e.g. 25 mph)
    11. iqr_upper: Interquartile range (IQR) calculated as p75 + 1.5 * IQR
    12. iqr_upper_freq: (frequency of cars above the iqr_upper) Count of vehicles driving above the iq_upper (considered outliers that are significantly faster than other vehicles)
    13. Daily cumulative counts for all Frigate-enabled objects since 0400 local time.
    14. Hourly cumulative counts by object for the last 36 hours.
    15. Daily cumulative counts by object for the last 10 days.
    16. Latest observations (to display images, Frigate snapshots must be enabled).
