# Build your own

A Traffic Monitor is a Raspberry Pi 5, a camera, an optional radar and AI accelerator, and a weather-resistant enclosure. Building one takes an afternoon.

1. [Hardware](https://docs.trafficmonitor.ai/dev/build-your-own-device-diy/recommended-hardware/index.md): the parts list, with the options that have been tested.
1. [Assembly](https://docs.trafficmonitor.ai/dev/build-your-own-device-diy/assembly-instructions/index.md): fitting the parts into the 3D-printed enclosure.
1. [Install the software](https://docs.trafficmonitor.ai/dev/software-installation/index.md): image the microSD card and run the installer.
1. [Update the software](https://docs.trafficmonitor.ai/dev/build-your-own-device-diy/update/index.md): when a new release comes out.

Then continue with [Choose a site and mount](https://docs.trafficmonitor.ai/dev/deployment-and-mounting-guide/index.md) and [First-time setup](https://docs.trafficmonitor.ai/dev/setup-guide/index.md).
